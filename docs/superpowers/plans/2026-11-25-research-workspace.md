# Codex 风格研究工作台实施计划

目标：按已确认的 ImageGen 设计重建现有 FastAPI 前端，真实对接研究流程。
架构：保留 Jinja 页面入口，CSS/JS 独立放入 static；同源调用后端，无需另建云端服务。
技术栈：FastAPI、SQLAlchemy、原生 JavaScript、CSS、marked、DOMPurify。

- [x] 后端：使用隔离 SQLite 和模拟模型调用，测试任务列表、输入校验、异步规划、持久化进度和规划异常。
- [x] 修复数据库默认配置，将规划移入工作线程，新增任务历史和配置接口，持久化步骤与错误。
- [x] 前端：实现灰白侧栏、输入卡片、研究建议、步骤详情、历史任务、报告阅读和导出；处理刷新恢复、断网重试、空状态、错误状态和窄屏。
- [x] 验证：运行后端测试和 JS 语法检查；浏览器检查桌面和手机布局、读取已有报告，以及模拟流程和异常交互。
- [x] 文档：记录启动方式、验证范围和设计稿位置。
